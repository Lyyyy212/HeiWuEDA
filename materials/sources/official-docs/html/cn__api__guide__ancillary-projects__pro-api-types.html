pro-api-types ​

嘉立创EDA & EasyEDA 专业版扩展 API 接口类型定义

    

使用 ​

建议使用 pro-api-sdk 进行扩展开发，本定义文件已在 SDK 内预配。

  1. 安装类型定义

    shell
    npm install --save-dev @jlceda/pro-api-types
    1

  2. 将 ./node_modules/@jlceda/pro-api-types/ 添加到 tsconfig.include 内

开源许可 ​

本类型定义使用 Apache License 2.0 开源许可协议，你仅可以将 嘉立创EDA、EasyEDA 商标信息用于依托于 pro-api-sdk 工具组开发的扩展包的 功能描述部分 和 开源发布的标题部分。
