# Contributing

Contributions are welcome for noncommercial use of the project.

By submitting a contribution, you confirm that you have the right to provide
it and agree that it may be distributed under the repository's applicable
license. Do not submit third-party code unless its provenance and compatible
license are documented.

Before opening a pull request:

1. Keep EasyEDA operations behind the guarded gateway and locked API manifest.
2. Preserve the default read-only behavior and explicit authorization gates.
3. Add or update tests for behavior changes.
4. Do not include live projects, evidence, backups, credentials, UUIDs or local
   absolute paths.
5. Run the validation commands in `README.md`.

Commercial-use requests are out of scope because commercial licensing is not
offered.
