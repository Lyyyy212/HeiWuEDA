# 黑五EDA 0.8.1 更新日记

发布日期：2026-08-27
发布者：Lyyyy

## 本次更新的目的

`0.8.1` 把此前仅存在于本地开发树中的专属嘉立创EDA连接器整理为公开源码模块。
从这一版开始，黑五EDA 不再只要求用户安装官方 Run API Gateway，也拥有独立命名、
独立连接状态和独立构建流程的 `黑五EDA Gateway`。

- 扩展名称：`黑五EDA Gateway`
- 扩展版本：`0.1.0`
- EasyEDA 引擎范围：`~3.2.0`
- 发布者：`Lyyyy`
- 许可证：`PolyForm-Noncommercial-1.0.0`
- 本地构建产物：`build/dist/zhiyuaneda-gateway_v0.1.0.eext`

## 连接方面的改进

1. 同时探测 `49620-49629`，不再逐个端口累计等待。
2. 保存最近一次成功端口，下次连接优先尝试该端口。
3. 专属 Bridge 和官方通用 Bridge 同时存在时，优先选择声明
   `lyyyy.zhiyuaneda` 身份的服务。
4. 连接失败后使用 `1s -> 2s -> 4s -> 8s -> 15s` 的有上限退避持续重连。
5. 连续两次心跳超时后才重新连接，降低 EasyEDA 短时卡顿造成的连接抖动。
6. 自动连接开关即时生效，状态窗口展示端口、模式、重试次数和最近错误。

## 与页面切换功能的关系

专属扩展负责稳定连接 EasyEDA 运行时；页面列表、UUID 绑定、指定页面激活、跨页读取后
恢复原页等能力仍由 `packages/easyeda-gateway` 中的受控导航层实现。连接成功不等于获得
写入权限，页面激活也不会自动保存或修改设计内容。

## 当前发布边界

该 `.eext` 是 GitHub 开发预览和本地联调候选，不是嘉立创EDA扩展广场正式提交包。
为了兼容现有 Python Gateway，它仍支持官方 Bridge 的 `execute` 消息。正式商店版需要把
该入口替换为固定、可审计的只读和短暂导航操作，并补齐商店图标与真实 EasyEDA 验收。

本次更新没有修改 EasyEDA 工程、原理图、PCB 或 BOM，也没有包含真实工程 UUID、页面
UUID、访问凭据和运行日志。
