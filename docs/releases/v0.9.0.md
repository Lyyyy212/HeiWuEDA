## 黑五EDA 工作台扩展 0.4.6

新增 `integrations/heiwu-workbench-extension/`，作为独立的协议 v2 只读开发预览：

- 专属身份：`lyyyy.hardware-workbench` / `hardware-workbench`；
- 拒绝任意代码执行和旧 `/execute` 通道；
- 仅开放操作目录、当前工程/文档上下文和身份绑定后的原理图索引读取；
- 使用固定 UUID、递增版本、Logo 与发布清单进行可重复 `.eext` 打包；
- 扩展详情只使用抽象教程图，不打包真实工程或飞书笔记截图。
