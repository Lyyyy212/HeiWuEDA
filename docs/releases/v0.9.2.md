# 黑五EDA 0.9.2 更新日记

- 发布日期：2026-09-03
- 发布者：Lyyyy

## 专属网关真正接入 skill

这次更新把专属网关身份放到了 Python Gateway、lifecycle skill、工作台扩展和公开文档的同一条契约里。skill 不再因为只看到 `easyeda-bridge` 服务名或某个端口，就误连到通用 Bridge。

可用连接必须同时满足：

```text
service = easyeda-bridge
gatewayId = lyyyy.hardware-workbench
productId = hardware-workbench
protocolVersion = 2
edaConnected = true
```

Bridge 只监听本机 `127.0.0.1:49620-49629`，实际 `bridgeUrl` 由启动时的空闲端口决定，因此 GitHub 记录的是发现范围和身份契约，而不是一个可能失效的固定端口。

## 两种扩展包

- `hardware-workbench_v0.4.14.eext` 是商店安全包，只开放 3 项固定只读操作。
- `hardware-workbench-local_v0.4.14.eext` 是项目专属本地包，额外开放经过配置档案和 SHA-256 摘要校验的 Gateway 操作，供完整 lifecycle skill 使用。

两种包从同一份源码构建，但文件名和安全边界明确分开。商店包不会因为本地功能加入源码而携带动态执行通道。
