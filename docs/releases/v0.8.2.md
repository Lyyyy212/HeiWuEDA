# ZhiYuanEDA 0.8.2 更新日记

发布日期：2026-08-27
发布者：Lyyyy

## 本次更新的目的

`0.8.2` 将本地最新版 JLC Hardware Learning 画板整理为可公开发布的 `0.1.6`。
本次不是只改版本号，而是把画板交互、首屏稳定性、页级网表和飞书学习笔记链路一起纳入
公开源码、版本锁、MCP 契约和 CI 验证。

## 画板交互更新

- 文字和便签的“小 / 中 / 大 / 特大”调整为 `13 / 15 / 20 / 28`，对应行高为
  `18 / 20 / 27 / 36`。
- 旧文字使用一次性版本迁移重新排版；学习框的位置、尺寸、编号和引用语义保持不变。
- 支持独立多画板、多图页，新画板保存在项目 `canvases/<uuid>/`，删除时先进入项目回收目录。
- 加强底图保护、多选移动、统一删除确认、文字双击编辑和本地 PNG/SVG/JSON 导出。

## 首次打开白屏修复

画板现在只观察自己的根元素尺寸。若 Codex 首次挂载时根元素暂时为 `0 x 0`，会使用有限
动画帧重试、延迟布局恢复以及 focus、visibility、pageshow 重新测量。该过程不会向宿主
反向报告全屏尺寸，也不会修改已保存的画板或相机状态。

## 页级官方网表

每张画板图页可以绑定一次官方 EasyEDA JLCEDA 网表旁车。绑定要求工程、文档和图页身份
一致；相同摘要可以幂等复用，不同身份或不同内容会阻止证据混合。元件和网络查询按范围
读取，不需要把整份网表加载到对话中。

## 飞书学习笔记

- 一个项目使用一个紧凑项目主页，`00..99` 分类作为主页内标题，不再创建多个空分类文档。
- 只有真实原理图页才创建独立 Docx；每页复用已有主画板和模块索引画板。
- 迁移和持续同步都先只读预览，给出精确目标、修订映射和 `planFingerprint`。
- 只有用户确认完全相同的预览后才能执行写入；写后必须 fresh read 验证，成功后才更新本地注册表。
- 持续同步只插入或替换 JLC 受管区，保留用户正文和原有两张飞书画板。

## 公开版本净化

- 排除本地 `docs/evidence/**` 验证材料。
- 将测试中的飞书租户 URL、token、项目 UUID 和图页 UUID 替换为明确的 Fixture。
- 新增 `materials/scripts/scan-public-release.mjs`，CI 会阻止私有证据目录、本地绝对路径、
  凭据字面量、真实租户 URL 和疑似真实身份值进入公开提交。
- Widget 构建前统一规范源码换行符，确保 Windows 本地构建和 Linux GitHub Actions
  生成相同的发布产物。
