# 更新记录

本文件记录黑五EDA 嘉立创EDA工作台扩展的公开候选版本。版本号遵循语义化版本；官方扩展更新必须沿用同一个 `uuid`，并使用严格递增的新版本号。

## [0.4.6] - 2026-08-28

### 发布

- 按嘉立创扩展商店要求，在 `extension.json` 中补充 GitHub 仓库信息。
- 将商店必填的名称、唯一标识符、显示名称、描述、版本、许可证和仓库纳入发布包自动校验。
- 将用户可见名称统一为黑五EDA，并更新到 `HeiWuEDA` 仓库地址。
- 公开包改用抽象教程图，排除真实工程和飞书笔记截图。

## [0.4.5] - 2026-08-28

### 修复

- 按嘉立创 `sys_WebSocket` 的真实运行约束，将 `49620-49629` 网关发现从并发探测改为逐端口探测，并在切换端口前关闭上一连接。
- 避免通用网关占用首个探测后阻断专属网关连接；保留 `0.4.4` 的五叶草头像和紧凑工作台。

## [0.4.4] - 2026-08-28

- 保持 420×520 工作台布局、连接状态、操作入口和 `0.4.3` 自动恢复连接修复不变。

## [0.4.3] - 2026-08-28

- 完整保留 `0.4.2` 的 420×520 紧凑状态工作台与详情页修改。
